# Day 1 Gitまとめ



## 1. Gitのどの機能が最も便利だと思いましたか？



ブランチ機能が便利だと思った。

作業を分けて進めることができ、他の作業に影響を与えずに開発できるため。



## 2. コンフリクトを解決するときに困ったことは？



コンフリクトが発生したときに、どの内容を残せばよいか最初は分かりにくかった。

実際に conflict.md を編集して、不要な記号を削除して解決する流れを学んだ。



また、最初はIssueを作成できなかったが、GitHub CLIの認証と

リポジトリのIssues設定を確認することで解決できた。



## 3. mergeとrebaseの違いを自分の言葉で説明してください



mergeは分岐した履歴を残したまま統合する方法。

rebaseは自分のコミットを最新のmainの後ろに付け替えて、

履歴を一直線にする方法。



## 4. 明日から実際の開発で使いたいGitコマンドは？



git status を使って、作業前やコミット前に現在の状態を確認したい。

また、git add、git commit、git pushを使って、こまめに変更を保存したい。
